# 阶段 1 · 对标基因拆解与五路异构导语工坊

小程序短篇的导语是**信息流买量广告切片（占生死权重的 40%）**。读者滑屏停留不超过 3 秒；导语不合格，正文写得再好也零点击、零投稿价值。

---

## 一、对标拆解五维雷达

### 1.1 仅有对标导语时（写入 `source_hook.md`）

先实测原导语的汉字数与有效段落数，再按以下 5 项给出**带原文依据**的拆解（严禁写“感觉很虐”之类的空话）：

1. **核心梗（一句话）**：最不可替代的设定或反转元素是什么？
2. **矛盾逻辑（伤害链条）**：谁施加伤害 → 通过什么具体手段 → 造成哪类不可逆损失 → **为什么主角当下不能立刻掀桌走人**（现实约束是什么：孩子、父母医药费、证据缺失、房产/债务捆绑）？
3. **权力关系位**：人物之间是什么婚姻、血缘或雇佣压迫关系？谁手里握着合法或世俗优势？
4. **情绪钩子类型与虐点落位**：
   - 物证暴击型（账本、病历、监控、金饰、结婚证）
   - 当众羞辱型（家宴、婚礼、病房、公司群）
   - 倒计时危机型（冷静期最后一天、拆迁签字截止、手术签字）
   - 双向/单向信息差型（他以为她在演，其实她快死了/已办完手续）
   - **标明具体虐点落在原文哪一句**
5. **句式节奏指纹**：首句是否直接抛矛盾（第几个字见血）？人称视角？有没有对白？结尾是用「冰冷物证」还是「戳心台词」收尾？

> 边界纪律：只有导语时，绝不臆测原文后半段结局。

### 1.2 拥有对标全文时（写入 `source_full.md`，进入阶段 2 前必拆）

除统计总章数、每章字数及情绪曲线外，**必须强制单独定位并拆解原文的「40% 付费墙卡点」**：

| 拆解字段 | 必须回答的具体内容 |
| :--- | :--- |
| **付费卡点章号** | 卡点落在第几章结尾（约占全文第几千字 / 百分比位置） |
| **卡前蓄压铺垫** | 卡点前一章如何给出“短暂希望”又当场粉碎，把读者的憋屈拉满 |
| **卡点最后 3 行** | 原文在卡点章最后 3 行停在哪个具体未闭合悬念上（如门被推开/大屏亮起/协议翻到最后一页） |
| **读者付费预期** | 读者此刻掏 9.9–39.9 元解锁后续，最想立刻看到的到底是什么画面 |

## 二、五路异构导语矩阵（告别单一换皮撞稿）

原版“只换道具和切面”的公式已被数百名作者同时复用，极易在编辑邮箱撞稿。生成 `cards.md` 时，**5 张卡必须分别采用以下 5 种正交变异策略**，且严格做到：

- **关系位守恒，社会身份全换**：如原为“全职太太 vs 出轨丈夫”，关系位是“受经济/情感依附的伴侣”，但职业必须全改且不重复；
- **首句动宾结构互异，零铺垫抛矛盾**：不介绍背景、不寒暄，第 1 句就给具体动作 + 具体伤害；
- **结尾标志物必换**：每张卡结尾的物证或台词载体不得沿用原导语道具；
- **长度贴近原导语节奏**：原导语 120 字则卡片写 110–160 字；原导语 350 字则卡片写 300–420 字；不人为注水拉长。

| 卡号 | 变异策略 | 核心操作定义 | 适用目标 |
| :--- | :--- | :--- | :--- |
| **卡一** | **切面平移 · 稳健保底型** | 保持核心梗与矛盾逻辑不变，改换冲突发生的公开程度、时间节点或物证载体。 | 贴合原爆款投放模型，过稿最稳 |
| **卡二** | **双梗杂交 · 高爆突围型** | 保留原对标的「强情绪困境壳」，杂交一层「高转化副梗底牌」（若无第二份素材，从下表副梗池抽取适配项）。 | 避免同质化撞车，拉高爽感上限 |
| **卡三** | **猎人设局 · 主动权倒置型** | 主角表面仍在受委屈不还嘴，实则暗中已收集完整证据/完成资产转移/办妥注销，结尾用一件已生效的冷静物证收尾。 | 贴合当下更爱看“清醒大女主”的读者 |
| **卡四** | **强现实痛点嫁接 · 买量高点击型** | 把矛盾嵌进三四线城市 30–40 岁女性最高频的现实痛点场景（如除夕团圆饭偏心、拆迁分房签字、陪嫁挪用、ICU 签字、礼金账本）。 | 信息流买量点击率（CTR）最高 |
| **卡五** | **信息差错位 · 生理级揪心型** | 利用信息不对等（如主角手里攥着病危单/公证回执/领养真相，反派却还在得意洋洋提条件），最后一击落在不可逆物证上。 | 虐点最狠、停留时长最长 |

### 内置高转化副梗池（供卡二杂交选用）

1. **假死/注销户籍脱身**：对方以为她在耍脾气离家出走，其实火化/注销回执早已寄到。
2. **遗产/拆迁款公证截胡**：婆家算计着等她签字放弃，公证员当场宣读被改过的真正遗嘱/拆迁份额。
3. **病历/孕检错位**：她拿着流产或绝症单独自签字，他正拿着别人伪造的孕检单在朋友圈官宣。
4. **行车记录仪/家用监控延时曝光**：当众泼脏水时，连接客厅电视或车机备份的云端录像自动回放。
5. **亲生/抱错/血缘账本反转**：熬干心血养大的孩子或扶持的亲戚，在关键时刻亲手把她推下水，转头发现真正托底的人不是他。
6. **暗中买断债权/反客为主**：看似被赶出家门身无分文，实则家里房子抵押权或店铺供货权早已在她名下。

## 三、下沉受众常识门禁与生活化词库映射

目标读者为**三四线城市 30–40 岁女性**。任何超越其日常生活感知的“悬浮设定”都会立刻破坏代入感、触发真人编辑秒拒。

### 3.1 黑名单禁区（禁止出现在角色设定与导语中）

- **悬浮/重工业生僻职业**：轧机工、锻造工、高炉操作员、精密仪器算法架构师、量化基金合伙人；
- **高门槛资本金融术语**：离岸家族信托、VIE 架构、对赌协议、期权池稀释、做空估值；
- **AI 生造伪医学词与翻译腔**：共患神经综合症、创伤后解离性痉挛、心脏骤停综合征、“我的天呐”、“他该死地迷人”。

### 3.2 高代入感替换词库

| 维度 | 禁用悬浮表达 | 推荐下沉高代入替换词 |
| :--- | :--- | :--- |
| **女主职业** | 轧机工、金融分析师、奢侈品买手 | 连锁金店店长、县医院护士、小学班主任、服装批发行老板娘、月子中心金牌月嫂、烘焙店主、小厂出纳会计 |
| **男主/反派职业** | 跨国财团继承人、PE 合伙人 | 本地包工头、汽修厂老板、连锁餐饮股东、科室主任、乡镇拆迁办经办人、县城体制内中层 |
| **核心利益载体** | 股权代持协议、期权行权书 | 房产证加减名、拆迁安置协议、陪嫁存折、首付转账凭证、门店营业执照、老人养老金卡 |
| **情绪引爆物证** | 加密硬盘、机密审计底稿 | 结婚证/离婚冷静期回执、ICU 病危通知书、医院流产/晚期化验单、行车记录仪内存卡、微信家庭群红包记录、刻字陪嫁金镯 |

## 四、卡片交付格式与「换名回读」硬门禁

### 4.1 标准输出格式（写入 `cards.md`）

```markdown
### 卡N｜策略：<策略名称>｜类型：<追妻火葬场 / 婆媳世情 / 原生家庭 / 悬疑反转>｜虐点强度：<强/中/轻>（强在：<物证/名分/身体/利益>）

<导语正文，严格贴合原导语字数与分段节奏，5 人名全不重复>

- 【保留的内核】核心梗：……｜矛盾逻辑：……｜关系位：……
- 【变异与验收】变异策略：……｜核心事件差异：……｜结尾道具变化：<原物> → <新物>
```

### 4.2 交付前逐卡硬核查（任一项不通过直接重写）

1. **换名回读自检**：把卡内人名和职业**替换回原导语的人名和职业**再默读一遍。如果还能读出“这不就是原导语那件事吗”，判定为伪换皮，立即作废重写。
2. **首句结构查重**：5 张卡的开篇第一句动宾结构不得与原导语同构，5 张卡之间也不能同构。
3. **常识查杀**：无重工业生僻职业、无高门槛金融黑话、无 AI 生造病名。
4. **交付即停**：写完 `cards.md` 并更新 `00_state.json`（`stage: "hooks"`）后，**必须停下请用户选卡**，不得擅自替用户选定后往下写。
